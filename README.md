# 생활 속 키오스크 체험

초등학교 3학년 학생들이 키오스크를 직접 사용하면서 불편한 점을 발견하고 해결 방법을 생각하는 수업용 앱입니다.

## 실행

`index.html`을 브라우저에서 열거나 정적 웹 서버에 폴더 전체를 올립니다. 크롬북 세로 화면과 터치 조작을 기준으로 제작했습니다. 별도 설치나 빌드가 필요하지 않습니다.

## 체험 장소

- 배스킨라빈스 31을 참고한 아이스크림 주문
- 푸드코트 음식 주문
- 기차역 승차권 발매
- 도서관 도서 검색과 대출

실제 결제, 회원 조회, 승차권 발권은 하지 않는 수업용 모의 체험입니다. 메뉴 선택, 낯선 용어, 시간 제한, 도서 상태와 소장 위치 확인 등 서로 다른 어려움을 경험하도록 구성했습니다.

## 자료 출처

운임과 수업 설계는 `운임 및 수업 설계.md`, 이미지 출처와 제작 기록은 `assets/이미지 제작 기록.md` 및 `assets/br/출처 및 제작 기록.md`에 정리했습니다. 배스킨라빈스 상품 사진과 이름은 해당 브랜드의 자료이며, 공식 서비스가 아닙니다. 글꼴 라이선스는 `assets/NotoSansKR-OFL.txt`를 참고하세요.

교과서 PDF와 개발 중 확인 자료는 저장소에서 제외했습니다.
